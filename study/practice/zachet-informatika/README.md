## Как пересобрать

Скрипты лежат в `src/`. Нужны `python-docx`, `openpyxl`, `Pillow`, LibreOffice (Writer + Calc) и `python3-uno`.

```bash
soffice --headless --accept="socket,host=localhost,port=2002;urp;" &
python3 src/build_task1.py /tmp/t1.docx && python3 src/update_toc.py /tmp/t1.docx "К заданию 1.docx"
python3 src/build_task2.py "К заданию 2.xlsx"
python3 src/build_task3.py /tmp/t3.xlsx && python3 src/add_pivot.py /tmp/t3.xlsx "К заданию 3.xlsx"
```
