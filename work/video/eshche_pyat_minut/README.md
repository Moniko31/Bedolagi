# «Ещё пять минут» — 3D-ролик на минуту (в работе)

Вертикальное видео 1080×1920, ~64 с, 3D в стиле Pixar, мальчик из `../boy_3d_test/`.

**Сюжет.** 06:47, будильник. «Ещё пять минут» — и вот ты летишь на облаке над городом. Открываешь глаза: 07:40,
автобус через пять минут! Зубы за три секунды, штаны на бегу, завтрак в зубах, бег через весь район…
Остановка пустая. И тут вспоминаешь: сегодня суббота. Ну что ж — ещё пять минут.

## Готово
- `zvuk_polnyj.m4a` — полная звуковая дорожка: диктор + своя музыка + шумы (−17 LUFS)
- `audio/` — реплики диктора (edge-tts `ru-RU-DmitryNeural`), все 15 проверены распознаванием Whisper
- `keys/` — референсы персонажа (лицо и 3D-кадр спальни)
- `src/` — сценарий, озвучка, шкала времени, микс, сборка, генерация кадров на Kaggle

## Не готово
Видео сцен: нужна бесплатная видеокарта. Kaggle держит GPU-задания в очереди, анонимный лимит
Hugging Face исчерпан до следующего дня. Когда будут клипы `clips/s01..s15.mp4`, ролик собирается одной командой.

## Сборка (из `src/`)
1. `python tts.py` — озвучка → `audio/`
2. `python mix.py` — музыка, шумы, микс → `build/audio.wav`
3. `python build_keys.py` → Kaggle-ядро кадров (SDXL DreamShaper + IP-Adapter face), затем видео Wan 2.2 → `clips/`
4. `python assemble.py` — подгонка клипов по времени, субтитры, финальная плашка → `eshche_pyat_minut.mp4`
