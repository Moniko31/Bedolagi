# «Мой сосед сверху» — 1 серия (пробное видео)

Вертикальное видео 1080×1920, ровно 60 секунд, мультфильм в стиле `../remontada/reference_frame_01.png` (плоская 2D-графика, толстый контур). Формат подсмотрен у ИИ-сериала «Мой худший сосед» из TikTok: только диалог, без диктора, короткие реплики с паузами, у каждого героя свой голос, под ними тихая музыка, субтитры с тире.

- `moy_sosed_sverhu_1.mp4` — готовое видео

**Сюжет.** Три часа ночи, Макса будит музыка соседки сверху. Он поднимается ругаться, а у Веры дым и мука: она сожгла торт к маминому юбилею. Макс сначала язвит («Это не торт. Это уголь»), потом останавливает закрывающуюся дверь, и до утра они вместе пекут новый торт. Следующим вечером Вера приносит ему кусок торта, и договариваются об ужине.

**Озвучка.** Макс говорит голосом edge-tts `en-US-AndrewMultilingualNeural` (~130 Гц), Вера голосом `en-US-AvaMultilingualNeural` (~225 Гц). Темп, высота и громкость подобраны под каждую реплику. Рот персонажа открывается по громкости его голоса. Звуки и музыка синтезированы в `mix.py`: глухой бас через потолок, который обрывается на «я выключу!», стук, скрип двери, «хлоп», «дзынь» духовки, дверной звонок и спокойная мелодия на фортепиано, которая вступает со слов «Будем печь заново».

## Сборка (из `src/`)
`python tts.py` → `python mix.py` → `python render.py video` → `ffmpeg -i build/video.mp4 -i build/audio.wav -c:v copy -c:a aac -shortest out.mp4`

- `script.py` — реплики, кадры и эмоции
- `timeline.py` — общая шкала времени и огибающие для липсинка
- `render.py` — отрисовка (Pillow)
- `mix.py` — голоса, шумы, музыка
